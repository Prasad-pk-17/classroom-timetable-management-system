# 🏫 Classroom & Timetable Management System

A web-based Classroom & Timetable Management System developed using **Python Flask and MySQL**.

The system helps manage classrooms, subjects, timeslots and generate timetables efficiently.

## 🚀 Features

- 🔐 Admin Login & Registration
- 🏫 Add, View, Edit and Delete Classrooms
- 📚 Add, View, Edit and Delete Subjects
- ⏰ Add, View, Edit and Delete Timeslots
- 📅 Generate Timetables
- 📊 Dashboard
- 🖨️ Printable Timetable Reports
- 🔑 Forgot Password & Reset Password
- 🗄️ MySQL Database Integration

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- Bootstrap
- Jinja2
- Git & GitHub
